КАК ОБНОВИТЬ УЖЕ ОПУБЛИКОВАННОЕ ДЕМО ЧЕРЕЗ GITHUB DESKTOP

1. Откройте GitHub Desktop. В Current Repository выберите escape-room-demo.
2. В Current Branch выберите ветку, из которой публикуется сайт (обычно main).
3. Нажмите Fetch origin. Если появилась кнопка Pull origin, нажмите её.
4. Выберите Repository → Show in Explorer. Откроется локальная папка репозитория.
5. В другом окне Проводника откройте обновлённую папку «демо» из проекта
   «Двор escape room». Скопируйте ВСЁ ЕЁ СОДЕРЖИМОЕ в папку репозитория,
   туда, где уже лежит index.html игры. При совпадении имён выберите
   «Заменить файлы в папке назначения». Папки classic, assets и vendor
   должны остаться на том же уровне вложенности, что и раньше.
   Если используете архив «демо.zip», сначала распакуйте его и затем
   скопируйте содержимое находящейся внутри папки «демо».
6. Вернитесь в GitHub Desktop. Во вкладке Changes появятся изменения.
   Среди них должны быть classic/index.html, classic/game.js и soundscape.js.
7. В поле Summary напишите: «Исправить звук и добавить экран загрузки».
   Нажмите Commit to main (или имя вашей ветки), затем Push origin.
8. Откройте репозиторий на GitHub и вкладку Actions. Дождитесь успешного
   завершения публикации GitHub Pages (зелёная отметка).
9. Откройте прежнюю ссылку на игру и нажмите Ctrl+F5 для обновления.
   Создавать новый репозиторий и заново включать GitHub Pages не требуется.

ПРОВЕРКА ОБНОВЛЕНИЯ
Сначала появляется «Дом просыпается…» с прогрессом загрузки.
После подготовки всех материалов открывается стартовый экран.
Нажмите «Открыть глаза» — фон дождя должен запуститься без выключения
и повторного включения звука. При загрузке файлов показывается ошибка
с кнопкой повтора, если соединение оборвалось или ожидание превысило 45 секунд.

Архив .zip загружать в репозиторий вместо файлов сайта не нужно.
Настройки публикации и ссылка на игру остаются прежними.
